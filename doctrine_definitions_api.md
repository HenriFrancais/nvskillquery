# NV Tools — Doctrine Definitions API

Returns all doctrine fit definitions with resolved skill requirements grouped by skillpack.

## Request

GET https://tools.novacancies.space/api/doctrine_definitions
Authorization: Bearer <your-token>

No parameters.

## Response

200 OK — JSON array of fits:

[
  {
    "doctrine": "Armor Battleships",
    "role": "DPS",
    "ship_type": "Megathron",
    "fit_name": "NV Megathron",
    "fit_eft": "[Megathron, NV Megathron]\n...full EFT...",
    "defining_items": ["Tracking Computer II", "%Antimatter Charge L%"],
    "skillpacks": {
      "Gunnery Core": [
        { "skill_id": 3307, "level_yellow": 4, "level_green": 5 }
      ],
      "[Autogenerated Required Skills]": [
        { "skill_id": 3392, "level_yellow": 4, "level_green": 5 }
      ]
    }
  }
]

- skillpacks is keyed by skillpack name; each value lists the skills that pack contributes to this fit (after specificity resolution).
- skill_id is the EVE type ID of the skill.
- level_yellow = minimum acceptable level; level_green = recommended level.
- defining_items are match patterns (% is a wildcard) used to identify the fit.

## Example

curl -H "Authorization: Bearer <your-token>" \
  "https://tools.novacancies.space/api/doctrine_definitions"
